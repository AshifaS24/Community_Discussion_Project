
# K-DISC Community Discussion Platform

## Project Overview

The K-DISC Community Discussion Platform is a web-based community discussion application developed to provide a centralized platform for users to create, view, and participate in discussions.

The platform integrates community discussion features with AI-powered functionality to improve the way users interact with and understand discussion content.

## Key Features

- User Registration and Login
- Session-based User Authentication
- User Profile
- Create and Manage Discussions
- View Community Discussions
- Comments and Replies
- Like and Engagement Features
- Bookmark Discussions
- Activity Tracking
- Search Discussions
- AI-Powered Discussion Summarization
- Sentiment Analysis
- Integration with K Community / Discourse
- Admin and User Management

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- Bootstrap
- JavaScript
- Google Gemini API
- Discourse API
